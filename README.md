## Requirements
- Python 3 (tested on 3.14.3)
- Git (tested on 2.53)

## Initial Setup

### Clone the repo
- Open a terminal and set the directory to where you keep your projects
- clone the repo, run: `git clone https://github.com/cassiev2/REST-API-PUBLIC-FETCH.git`
- change the directory to the new folder: `cd REST-API-PUBLIC-FETCH`
### Create the virtual environment
- load python built-in venv package and create "venv" folder for its toolbox, run: `python -m venv venv`
- Enter virtual environment, run: `.\venv\Scripts\activate`
- confirm prompt looks like this: "(venv) PS D:\GitHub\REST-API-PUBLIC-FETCH>"
### Install Flask
- Install the Python package "Flask", which enables web framework code functionality, run: `pip install "flask[async]" httpx`

## How to run it
- open a terminal and set the directory to the repo folder
- Enter virtual environment, run: `.\venv\Scripts\activate`
- confirm prompt looks like this: "(venv) PS D:\GitHub\REST-API-PUBLIC-FETCH>"
